# Установка
Приложение распространяется неподписанным ipa файлом (в releases), соответственно его необходимо подписать сертификатом разработчика например через sideloadly.
Также можно самостоятельно собрать приложение через Xcode при помощи исходного кода размещенного в репозитории.

# Основная цель приложения
Основной целью приложения является предоставления дополнительных функций и удобств для пользователя при использовании проекта <a href="https://github.com/qiaelel/historydatesapp">historydatesapp</a>.
На данный момент основная доп. функция приложения это оффлайн доступ, но также планируются и другие интересные функции.

# Требования
iOS, iPadOS 15.6+ (MacOS 12+ (arm), VisionOS 26+)
Xcode 26.3+
